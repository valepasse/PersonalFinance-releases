# PersonalFinance — downloads

A personal finance app for macOS and Windows. This repository only holds the downloads and the update
feeds; the source code is private.

Get the latest version from [Releases](https://github.com/valepasse/PersonalFinance-releases/releases/latest).
Once installed, the app checks for new versions by itself and asks before updating.

## macOS (14 or later, Apple silicon)

1. Download `PersonalFinance-<version>-macOS.zip`, open it and drag **PersonalFinance** into Applications.
2. The app isn't signed by an Apple developer account, so the first time macOS blocks it: open
   **System Settings → Privacy & Security** and click **Open Anyway** next to PersonalFinance.

## Windows (10 or 11)

1. Download and run `PersonalFinance-win-x64-Setup.exe` (or `win-arm64` on ARM PCs).
2. The app isn't signed, so SmartScreen may warn you: click **More info → Run anyway**.

# PersonalFinance — download

App di finanza personale per macOS e Windows. Qui ci sono solo i download e i file per gli
aggiornamenti; il codice sorgente è privato.

Scarica l’ultima versione da [Releases](https://github.com/valepasse/PersonalFinance-releases/releases/latest).
Una volta installata, l’app controlla da sola le nuove versioni e chiede prima di aggiornarsi.

**macOS:** scarica lo zip, trascina PersonalFinance in Applicazioni; al primo avvio apri
**Impostazioni di Sistema → Privacy e sicurezza** e scegli **Apri comunque**.

**Windows:** esegui il `Setup.exe`; se SmartScreen avvisa, scegli **Ulteriori informazioni → Esegui comunque**.
